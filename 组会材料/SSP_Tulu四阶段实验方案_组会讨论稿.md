## SSP 复现与扩展实验方案（组会讨论稿）

**版本：** v1.0  
**日期：** 2026-07-29  
**实验资源：** 单卡 NVIDIA RTX 3090 24GB，预计连续使用 1–2 周  
**本次组会目标：** 确认研究主张、复现边界、主要终点、计算预算和阴性结果的解释框架。

> **一句话方案：** 先用论文的六条件消融确认“在语义步骤边界施加 STP 是否比随机 token 采样更能塑造可预测的推理轨迹”，再用同一套几何指标比较 Tulu-3-8B 的 Base、SFT、DPO、RLVR 四阶段，重点检验 DPO→RLVR 是否发生无法由最终答案准确率充分解释的轨迹几何重组。

# 0. 组会摘要

## 0.1 为什么要做

已有四阶段行为评测没有给出稳定的 DPO→RLVR 增益：

- seed 1–3、pass@12 汇总中，RLVR−DPO 约为 **+0.6 个百分点**，95% CI 为 **[-2.4, +3.6]**；
- seed 1–4、pass@16 汇总中，DPO 为 **79.2%**、RLVR 为 **80.6%**，差值 **+1.4 个百分点**，95% CI 为 **[-1.4, +4.4]**。

这说明仅凭最终答案正确率，很难判断 RLVR 是否改变了模型内部的推理组织方式。SSP 论文提供了一个可操作的工具：在推理步骤边界上测量隐藏状态的多步可预测性、平滑性和非线性结构。本研究据此把问题从“RLVR 是否更准”推进到：

> **后训练四阶段是否沿着不同方式组织推理轨迹？其中 DPO→RLVR 是单纯的行为波动，还是内部轨迹几何的系统重组？**

## 0.2 两个相互独立但互相支撑的子研究

1. **方法复现层：SSP 的 Tulu-3-8B 端口**
   - 共同从 Meta-Llama-3.1-8B Base 出发，运行 B1/B2/C/A2/A/A1 六条件。
   - 主要回答：连续语义步骤边界 STP（A）是否优于随机 token STP（C）。
   - 主要终点：末层 normalized MSE@1，比较 A 与 C。

2. **机制研究层：Tulu 四阶段冻结诊断**
   - 比较已有 Base、SFT、DPO、RLVR，不重新定义它们的训练过程。
   - 主要回答：后训练是否重组轨迹几何，尤其是 DPO 与 RLVR 的差异。
   - 主要终点：题目配对的末层 normalized MSE@3，比较 DPO 与 RLVR。

这两个子研究必须分开报告：SSP 端口失败不等于四阶段没有几何差异；四阶段差异为零也不等于 SSP 方法无效。

## 0.3 建议本次组会确认的六项决定

1. 是否同意把“**四阶段轨迹重组**”作为主研究主张，而不是把 RLVR 行为增益作为前提。
2. 是否同意当前先做 **Tulu-only 方法端口**，Qwen 原模型严格复现延期。
3. 是否接受本轮用 **MATH-500 轨迹**完成主分析，ProcessBench 延期为外部验证。
4. 是否接受 **DPO vs RLVR 的 MSE@3**为机制研究主终点、A vs C 的 MSE@1 为方法端口主终点。
5. 是否接受 24 小时测速后按 **总预计时长不超过 14 天**自动继续的计算规则。
6. 是否接受“结构性排序与稳健效应”为复现目标，而不把论文中的 168×作为硬性成功门槛。

# 1. 研究问题、假设与可证伪结论

## 1.1 总研究问题

Tulu-3-8B 从 Base 经 SFT、DPO 到 RLVR 后，推理轨迹隐藏状态的可预测性、局部平滑性和非线性结构如何变化？这些变化能否揭示最终答案准确率之外的后训练机制？

## 1.2 预注册式假设

### H1：SSP 采样位置效应

在相同 Base、训练数据、NTP 目标和训练预算下，连续步骤边界 STP（A）的末层 normalized MSE@1 低于随机 token STP（C）。

- **关键对比：** A vs C。
- **解释：** 若成立，说明改善来自语义对齐的采样位置，而不只是加入 STP 损失。
- **反证：** A 与 C 无稳定差异，或优势只在量化态/特定切步规则下出现。

### H2：步骤级结构与连续性分别贡献

- C vs A2 隔离“token 位置”与“步骤边界”；
- A2 vs A 隔离“随机步骤”与“连续步骤”；
- C-match/A2-match 检查效果是否只是由每条轨迹参与损失的三元组数量不同造成。

### H3：DPO→RLVR 发生轨迹几何重组

在同一 MATH-500 题目上，DPO 与 RLVR 的末层 MSE@3、层深曲线、平滑性或 MLP 可预测性存在系统差异。

- **主对比：** DPO vs RLVR 的题目配对 MSE@3。
- **为什么选 MSE@3：** 比一步预测更能反映多步轨迹组织，同时比更长跨度拥有更高有效样本覆盖率。
- **允许的阴性结论：** 如果置信区间排除有意义的差异，可得出“RLVR 的现有行为变化未伴随可检测的多步轨迹重组”，这本身具有机制信息。

### H4：几何可预测性不等同于任务正确性

更低的 MSE 或更平滑的轨迹不必然带来更高的 MATH-500 正确率。行为评测用于检验几何塑形是否损害生成能力，而不是把“越平滑越正确”作为默认假设。

### H5：轨迹更可能是平滑曲线而非直线

残差 MLP 相对线性外推的改进用于判断非线性可预测结构。DPO↔RLVR 的跨阶段迁移进一步检验两个阶段是否共享同一局部轨迹规律。

# 2. 原论文实验：要复现的核心是什么

## 2.1 原论文的核心命题

Yuan（2026）的 SSP 工作在原始 Semantic Tube Prediction（STP）基础上，只改变 STP 损失的采样位置：从随机 token 三元组改为推理步骤边界三元组。论文主张，**采样位置而非损失形式本身**是产生可预测推理轨迹的关键变量。

STP 损失约束相邻隐藏状态位移方向近似平行：

`L_STP = 1 − cos(h_r − h_s, h_t − h_r)`

SSP 在步骤标记位置上使用连续步骤三元组，并以：

`L = L_NTP + β · L_STP，β = 1`

进行训练。

## 2.2 原论文六条件消融

| 条件 | NTP | STP | 采样位置 | 该条件回答的问题 |
|---|---|---|---|---|
| B1 | 否 | 否 | 无，冻结预训练模型 | 未微调基线是什么水平？ |
| B2 | 是 | 否 | 无 | 普通语言模型微调本身带来多少变化？ |
| C | 是 | 是 | 随机 token | 原始 STP 的效果是什么？ |
| A2 | 是 | 是 | 随机步骤边界 | “步骤边界”本身是否重要？ |
| A | 是 | 是 | 连续步骤边界 | 连续语义步骤是否进一步重要？ |
| A1 | 否 | 是 | 连续步骤边界 | NTP 与几何纯度之间是否存在权衡？ |

## 2.3 原论文的公开设置

- 主模型：Qwen2.5-Math-1.5B。
- 训练数据：6,132 道 MATH 题目及解答，按段落划分步骤。
- 训练：3 epochs，约 1,150 optimizer steps。
- 参数高效微调：LoRA rank 16，作用于 q/k/v/o projections。
- STP 权重：β=1。
- 主评测：ProcessBench 3,400 条人工标注的逐步数学解答。
- 主指标：normalized multi-step prediction MSE、cosine score、perpendicular score。
- 补充分析：线性外推、3 层残差 MLP、解码一致性、GSM8K greedy 准确率。

## 2.4 原论文主结果（用于校准方向，不作为数值硬目标）

| 条件 | MSE@1 | MSE@3 | 相对 B1 的 MSE@1 改进 |
|---|---:|---:|---:|
| B1 | 0.955 | 5.688 | 1× |
| B2 | 0.600 | 2.797 | 1.6× |
| C | 0.226 | 0.836 | 4× |
| A2 | 0.010 | 0.155 | 96× |
| A | 0.006 | 0.093 | 168× |
| A1 | 0.006 | 0.116 | 152× |

论文还报告：A 与 B2 的 GSM8K greedy 准确率相同，而 A1 的 MLP 可预测性更强，体现 NTP 的生成质量与“几何纯度”之间可能存在权衡。

## 2.5 严格复现面临的信息缺口

截至 2026-07-29，论文给出的 SSP GitHub 地址格式异常且对应仓库不可用；论文正文未完整报告学习率、batch size、梯度累积、优化器、warmup、weight decay、最大长度、随机种子和新增步骤 token 的初始化方式。

因此，本研究把设置分成四类并在结果中明确标注：

1. **论文明确设置：** 六条件结构、LoRA rank 16、q/k/v/o、β=1、3 epochs、步骤边界定义和主要几何指标。
2. **从原始 STP 公开实现继承：** 学习率 2e-5、LoRA alpha 32、dropout 0.1、线性学习率调度、无 warmup 等。
3. **RTX 3090 工程适配：** QLoRA、micro-batch 1、梯度累积 16、2048 token 训练长度、单卡串行执行。
4. **本研究新增：** 四阶段冻结比较、MATH-500 配对轨迹、全层深曲线、计数匹配控制、跨阶段 MLP 迁移。

# 4. 本研究的具体实验设计

## 4.1 子研究 I：冻结四阶段几何诊断

### 模型

- Base：Meta-Llama-3.1-8B。
- SFT：Llama-3.1-Tulu-3-8B-SFT。
- DPO：Llama-3.1-Tulu-3-8B-DPO。
- RLVR：Llama-3.1-Tulu-3-8B。

全部以 BF16、非量化方式提取激活，不对模型参数做更新。

### 轨迹库

- 来源：已有 DPO 与 RLVR 的 MATH-500、多 seed、多采样回答。
- 以题目为配对单位；每题内对 DPO/RLVR 使用等量、同采样层级的有效轨迹，先在题目内聚合，再做跨题统计。
- 有效轨迹要求：正常停止、非空、不超过 2048 token、至少可切出 3 个步骤。
- 现有预审计显示约 492/500 题可形成 DPO/RLVR 有效配对。
- 主边界：自然段落步骤的最后一个 token。
- 敏感性分析：semantic-clean 切步；字面量 `<|step|>` 边界。

### 测量

- 层：4、8、12、16、20、24、28、32。
- 位置：各 decoder layer 输出、最终 RMSNorm 之前。
- 指标：normalized MSE@1/2/3/5、cosine score、perpendicular score、层间平滑性。
- decode 检查：最多 200 个点，检验几何接近是否对应 LM head 功能接近。
- 主终点：DPO vs RLVR 的题目配对末层 MSE@3。

## 4.2 子研究 II：Tulu-8B SSP 六条件训练

### 统一训练设置

- 共同起点：Meta-Llama-3.1-8B Base。
- 训练格式：plain question + step-token 分隔的 solution。
- QLoRA：NF4、double quant、BF16 compute。
- LoRA：rank 16、alpha 32、dropout 0.1，q/k/v/o。
- AdamW，learning rate 2e-5，linear schedule，warmup 0，weight decay 0。
- 3 epochs；micro-batch 1；gradient accumulation 16；gradient checkpointing；关闭 KV cache。
- STP 权重 β=1。
- NTP 只计算回答区域，不对题目 prompt 计算损失。
- 所有随机三元组在训练前按 seed 固化并写入 manifest。

### 条件与种子

| 条件 | seed 42 | seed 43/44 | 行为 greedy | pass@4 |
|---|---:|---:|---:|---:|
| B1 | 冻结 | 否 | 是 | 是 |
| B2 | 是 | 是 | 是 | 是 |
| C | 是 | 是 | 是 | 是 |
| A2 | 是 | 是 | 是 | 是 |
| A | 是 | 是 | 是 | 是 |
| A1 | 是 | 否 | 是 | 否 |
| C-match | 是 | 否 | 是 | 否 |
| A2-match | 是 | 否 | 是 | 否 |

### 为什么增加计数匹配控制

A 使用所有连续步骤三元组，而随机采样条件可能每条轨迹只产生较少三元组。如果 A 优于 C/A2，差异可能来自更密集的 STP 监督，而不是“连续步骤”本身。C-match/A2-match 将监督数量匹配到 A，用于排除这一替代解释。

## 4.3 训练后主评测

1. 将 QLoRA adapter 合并到 BF16 Base。
2. 用固定样本比较 4-bit adapter 态与合并 BF16 态，量化推理差异。
3. 在训练保留 token 位置完成主几何评测。
4. 在自然段落边界上测试几何效果是否可迁移。
5. 全部核心条件运行 MATH-500 greedy。
6. B1/B2/C/A2/A 追加 pass@4：temperature=0.6、top_p=0.95、最大生成 16k token。
7. 行为非退化判据：A−B2 的 MATH-500 准确率不低于 −2 个百分点。

## 4.4 残差 MLP 与跨阶段迁移

- 预测器形式：线性外推结果 + 3 层残差 MLP 修正。
- 主切分：problem-level train/dev/test，确保同题轨迹不跨集合。
- 敏感性：pair-level 80/20 切分，用于评估结果对切分单位的依赖。
- 同阶段拟合：分别测量每个模型的非线性可预测性。
- 跨阶段迁移：DPO 上训练、RLVR 上测试，以及反方向测试。
- 解释：
  - 双向迁移良好：两个阶段共享局部轨迹规律，差异可能主要是尺度或噪声。
  - 单向迁移：一个阶段的轨迹规律包含另一个阶段，但反之不成立。
  - 双向迁移差：DPO→RLVR 可能改变了局部动力学结构。

# 5. 指标、统计与结论规则

## 5.1 主要终点

| 子研究 | 主要比较 | 主要指标 | 统计单位 |
|---|---|---|---|
| SSP 方法端口 | A vs C | 末层 normalized MSE@1 | problem；跨 seed 汇总 |
| 四阶段机制 | RLVR vs DPO | 末层 normalized MSE@3 | MATH-500 题目配对 |

## 5.2 次要终点

- C vs A2、A2 vs A、A vs A1。
- Base/SFT/DPO/RLVR 的完整层深曲线。
- MSE@2/5、cosine、perpendicular、decode 一致性。
- A vs B2 的行为非退化。
- MLP 相对线性外推的误差比。
- DPO↔RLVR 跨阶段迁移。

## 5.3 统计方法

- 先在题目内聚合轨迹，避免“轨迹多的题目”获得过大权重。
- DPO/RLVR 使用题目级配对差值。
- 10,000 次 bootstrap，报告 95% CI。
- 多 seed 条件报告 seed 均值、离散度和每个 seed 的原始结果。
- 不只报告 improvement factor，同时报告绝对 MSE，避免基线接近零时比值失真。
- 主终点和次要/探索性分析分开呈现，不在看到结果后更换主指标。

## 5.4 科学结论矩阵

| 结果模式 | 可支持的结论 | 不能直接推出的结论 |
|---|---|---|
| A<C 且行为不退化 | 步骤边界采样能塑造更可预测轨迹 | 不能自动推出推理更正确 |
| A<C 但准确率明显下降 | 存在几何纯度与生成质量权衡 | 不能把低 MSE 当作方法成功的唯一标准 |
| A≈C | Tulu-8B/QLoRA/MATH 设置下未复现采样位置效应 | 不能否定原论文在 Qwen+ProcessBench 上的结果 |
| RLVR<DPO（MSE） | RLVR 轨迹更易多步外推 | 不能等同于 RLVR 准确率更高 |
| RLVR>DPO（MSE） | RLVR 可能增加探索性、曲率或局部非线性 | 不能简单称为“几何退化” |
| RLVR≈DPO | 现有 RLVR 行为变化未伴随可检测重组 | 不能排除其他层、其他任务或其他几何量上的差异 |

# 6. 与研究问题的因果关系

## 6.1 为什么不能只比较四个冻结模型

Base、SFT、DPO、RLVR 的数据和训练目标同时变化。直接观察四阶段差异只能说明“阶段相关”，不能说明是何种几何约束导致。因此需要六条件 SSP 网格提供一个受控的机制参照：当我们主动改变步骤采样位置时，哪些几何指标应该如何响应。

## 6.2 为什么六条件全部从 Base 出发

若分别从 SFT、DPO 或 RLVR 继续训练 SSP，起点能力、词表、数据分布和优化历史会混入条件差异。共同 Base 起点确保 A vs C 等比较具有明确的干预解释。冻结四阶段分析则保留真实后训练链条，回答自然发生的重组问题。

## 6.3 为什么主要比较 DPO 与 RLVR

DPO 和 RLVR 最接近研究关心的“偏好优化→可验证奖励强化”转变；已有 pass@12/pass@16 差异小且置信区间跨零，正适合检验“行为近似时内部结构是否仍发生变化”。

## 6.4 为什么把 MSE@1 和 MSE@3 分别设为两个主终点

- MSE@1 最贴近原论文的核心 168×主张，适合作为方法端口的复现终点。
- MSE@3 对多步轨迹重组更敏感，且现有轨迹覆盖足以支持题目配对，适合作为四阶段机制终点。
- 预先分开可以避免在多个 horizon 中事后挑选最显著结果。

# 7. 风险、缓解措施与剩余不确定性

| 风险 | 可能影响 | 当前缓解措施 | 仍需注意 |
|---|---|---|---|
| 论文实现细节缺失 | 难以声称完全严格复现 | 明确区分论文设置、STP 继承、工程适配和新增项 | 结果与论文不一致时无法唯一定位原因 |
| 8B+3090 训练成本 | OOM、速度过慢、无法完成多 seed | QLoRA、batch 1、累积 16、24h 测速、14 天上限 | QLoRA 本身可能改变优化动力学 |
| QLoRA 与论文 LoRA 不同 | 几何效果可能被量化噪声改变 | 主评测使用合并 BF16，并做 4-bit/BF16 固定样本对比 | 无法完全等价于全 BF16 LoRA 训练 |
| Tulu 与 Qwen 模型域不同 | 不应期待精确复现 168× | 以结构排序和方向为目标 | 阴性结果只能说明端口未复现，不能直接否定论文 |
| MATH-500 代替 ProcessBench | 缺少步骤级人工错误标签 | 聚焦轨迹预测与答案级行为；ProcessBench 延期 | 对“平滑与正确性的关系”证据较弱 |
| 步骤切分误差 | 边界噪声直接影响 STP 和 MSE | 段落主规则、语义清洗敏感性、完整步骤截断 | 句子回退可能混入非语义边界 |
| 保留 token 具有既有嵌入 | 可能不是中性步骤标记 | 字面量 `<|step|>` 与自然边界敏感性分析 | 不能完全复现新增专用 token 的初始化 |
| DPO/RLVR 有效轨迹筛选 | 形成 survivor bias | 固定资格规则、报告 492/500 覆盖和排除原因 | 长/短轨迹分布差异仍可能影响比较 |
| 三元组监督数量不同 | A 的优势可能来自监督密度 | C-match/A2-match | 控制增加训练预算 |
| MLP 过拟合或题目泄漏 | 虚高非线性可预测性 | problem-level 主切分、early stopping、pair-level 敏感性 | 8B hidden dimension 下样本量仍有限 |
| pass@4 方差较大 | 非退化结论精度有限 | 全条件 greedy、关键条件 pass@4、保留逐题结果 | 若接近 −2 pp 边界，需追加采样 |
| 长生成占用大量时间 | 挤压几何主实验 | 核心训练与几何优先，行为评测后置 | 16k 上限仍可能成为主要耗时项 |
| 后台任务静默失败 | 浪费 GPU 时间或产生不完整结果 | tmux、阶段状态文件、每 2 小时 Codex 检查 | 监测只报告，不自动改参或重试 |

# 8. 执行顺序、时间治理与监测

## 8.1 执行顺序

1. 环境、模型路径、tokenizer 与步骤 token 合约检查。
2. 构建训练数据 manifest 和冻结四阶段 trace bank。
3. 先跑冻结四阶段几何诊断，获得低成本可行性信号。
4. 启动 seed 42 的首个正式 QLoRA 条件。
5. 运行 24 小时后估算完整核心网格耗时。
6. 若预计不超过 14 天，则自动继续 B1/B2/C/A2/A/A1；否则在当前单元安全结束后暂停。
7. 核心网格完成后，优先运行 C-match/A2-match。
8. 资源允许时再补 B2/C/A2/A 的 seed 43、44。
9. 合并 BF16、几何评测、MATH-500 行为评测。
10. 最后运行 MLP、跨阶段迁移和统计汇总。

## 8.2 后台运行与监测

- tmux 会话名：`ssp-tulu-runner`。
- 单 GPU 串行运行；每个实验单元有独立日志、状态 JSON、checkpoint、完成/失败标记。
- 技术失败立即停止流水线，不自动重试，不暗改参数。
- Codex 每 **2 小时**检查：
  - 当前条件、epoch、global step、速度和 ETA；
  - GPU 利用率、显存、温度；
  - 磁盘余量；
  - 总损失、NTP/STP 分项损失；
  - NaN、OOM、traceback、tmux 消失和日志停滞；
  - checkpoint、结果文件和已完成阶段的初步指标。
- 每次检查均提交简短进度；出现错误、磁盘风险或预计超期时立即额外报告。
- 监测只观察和汇报，不自动修改超参数。

## 8.3 粗略时间预算

| 阶段 | 预计时间 | 决策点 |
|---|---|---|
| 预检、数据与 trace bank | 0.5–1 天 | 数据覆盖和 token 合约是否通过 |
| 冻结四阶段诊断 | 约 0.5–1.5 天 | 指标与激活提取是否稳定 |
| 首个 QLoRA 条件 | 先观察 24 小时 | 推算完整网格是否≤14天 |
| seed 42 核心网格 | 以实测为准 | 核心优先，不因科学阴性停止 |
| 匹配控制与额外 seed | 视余量追加 | 匹配控制优先于额外 seed |
| 行为、MLP 与汇总 | 约 2–4 天 | 若超时，先交付主终点 |

# 10. 预期产出

## 10.1 实验产出

- 可复用的训练、激活提取、几何评测、行为评测和统计代码。
- 数据、模型、随机三元组和运行环境 manifest。
- 六条件与计数匹配控制结果表。
- Base/SFT/DPO/RLVR 层深几何曲线。
- DPO/RLVR 题目级配对统计。
- 量化态、边界定义、切分方式和种子敏感性分析。
- 每 2 小时监测记录、24 小时吞吐报告和最终计算账单。

## 10.2 可能形成的论文叙事

### 叙事 A：方法端口成功，四阶段存在重组

SSP 的采样位置效应可迁移到 Tulu-8B；RLVR 在行为近似的情况下显著改变多步轨迹几何，说明后训练机制不能只由最终正确率刻画。

### 叙事 B：方法端口成功，四阶段无明显重组

几何指标对受控 STP 干预敏感，但 DPO→RLVR 没有稳定差异，表明现有 RLVR checkpoint 的内部改变可能比预期局部，或主要体现在本指标之外。

### 叙事 C：方法端口不成功，四阶段仍有差异

SSP 的具体训练效应未迁移到 8B QLoRA 设置，但其诊断指标仍揭示四阶段差异；需要把“方法复现”和“指标借用”严格分开。

### 叙事 D：两层结果均为阴性

若置信区间足够窄且敏感性分析一致，可形成对 SSP 跨模型迁移边界和 Tulu 四阶段几何稳定性的负结果；若区间过宽，则只能视为算力受限的未决结果。
